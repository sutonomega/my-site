# Echo Note サイト仕様

## 画面と移動

| 画面 | URL | 動作 |
| --- | --- | --- |
| ホーム | `https://www.galpachi.com/` | サイト紹介、YouTubeプレイリスト、作品一覧、SNSへのリンクを表示する。 |
| 曲詳細 | `https://www.galpachi.com/?slug=<曲ID>` | 曲名、公開日、タグ、紹介文、再生ボタン、登録済みの外部リンク、歌詞を表示する。URLを直接開ける。公開用IDは自動生成される。旧URLからも同じ曲を開ける。 |

作品一覧はタグを1つ選んで絞り込める。同じタグを再度押すと絞り込みを解除する。曲カードはリンクとして開ける。ブラウザーの戻る・進む操作はURLに対応する画面を表示する。一覧に戻ると絞り込みは解除される。

## 再生

- 曲詳細の再生ボタンでMP3を読み込み、ミニプレーヤーを表示する。
- ミニプレーヤーで再生・一時停止・音量変更ができる。音源の長さが確定すると、再生位置を変更できる。
- 同じページ内で一覧や別の曲詳細に移っても再生は続く。別の曲を再生すると音源が切り替わる。
- 同じブラウザーでページを再読み込みすると、保存された曲と位置を復元する。ブラウザーが自動再生を制限している場合は、再生ボタンを押して続きから聴ける。保存領域を使えない場合も手動再生できる。

## 取得できない場合

| 状況 | 表示・操作 |
| --- | --- |
| 曲IDが一覧にない | 曲が見つからない旨と一覧へのリンクを表示する。 |
| 曲一覧の取得に失敗 | 読み込み失敗の案内を表示する。 |
| 歌詞が空、未公開、または取得できない | 歌詞が未公開である旨を表示する。 |
| 音源の取得・再生に失敗 | ミニプレーヤーに案内を表示する。取得エラー時は再生ボタンで再試行できる。 |

曲ページの移動と再生のエラー処理は [#4](https://github.com/sutonomega/my-site/issues/4) と [#5](https://github.com/sutonomega/my-site/issues/5) を参照。
